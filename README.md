# Bigboss Law — Demo miễn phí

Bản demo tĩnh của ứng dụng quản lý hãng luật, dành cho GitHub Pages. Chọn **Mở bản minh họa** để vào với quyền quản trị demo.

- Không cần Firebase, thẻ thanh toán, mật khẩu hoặc máy chủ backend.
- Dữ liệu chỉ là mẫu trong tab trình duyệt; tải lại trang sẽ đặt lại dữ liệu.
- Có thể bấm thử hồ sơ, khách hàng, công việc, lịch, tài liệu, thu/chi và tra cứu bằng mã đã cấp trong cùng tab.
- Không nhập thông tin thật hoặc dùng bản demo để lưu trữ hồ sơ khách hàng.
- Không có xác thực hoặc lưu trữ dữ liệu production trong bản này.

## Bật website miễn phí

Repository Settings → Pages → Build and deployment:

1. Source: Deploy from a branch.
2. Branch: bigboss-law-demo-site, folder: / (root).
3. Save. Chờ GitHub Pages hiển thị trạng thái triển khai thành công.

Địa chỉ dự kiến sau khi Pages được bật: https://lts9x.github.io/Sang-Lee/

Việc đẩy nhánh chứa tệp HTML không tự bật cài đặt GitHub Pages. Website chỉ hoạt động sau khi chủ repository bật Pages và deployment thành công.
